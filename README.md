# Hemlock & Hammer — Project Briefs

Public project briefs for active and recent **Hemlock & Hammer** construction projects on Whidbey Island and surrounding Pacific Northwest communities.

These are working documents — internal-grade project briefs published for the convenience of homeowners, subcontractors, dealers, and inspection authorities involved in each project. They reflect H&H's pre-construction scoping discipline and serve as a single source of truth for project-specific data.

## Structure

Each project lives in its own subdirectory containing a single self-contained `index.html` with the project brief. Briefs are inline — no external assets, no build step, no dependencies. They render the same on a phone, a laptop, or a printed page.

```
hemlock-and-hammer-projects/
├── README.md
├── index.html                     # umbrella landing page
└── 1080-village-loop/
    └── index.html                 # 1080 Village Loop project brief
```

## A Note on Public Information

These briefs include property identification, ownership tenure, and tax history information that is publicly available through the Island County Assessor's office and standard real estate listings. No information is published here that is not already a matter of public record. Project briefs are not legal, financial, or design recommendations — they are working tools for the H&H team and project participants.
